# BinaryCipher PRO v5.0 | Ultimate Cyber Security & Crypto Suite

![BinaryCipher PRO Banner](https://vexornull.github.io/favicon/favicon.png)

> **BinaryCipher PRO v5.0** is an enterprise-grade, next-generation online data encryption, multi-format translation, cryptographic hashing, and cyber utility suite. Engineered for security professionals, developers, and enthusiasts.

---

## 🚀 Key Features & Upgrades in v5.0

1. **Enterprise Crypto & Universal Encoder:**
   - Instant text conversion to **Binary**, **Hexadecimal**, **Decimal**, and **Base64**.
   - Cryptographic hashing support including **SHA-256** and **MD5**.
2. **Interactive QR Code Generator:**
   - Instantly convert your processed or encrypted output into a high-density scannable QR code modal.
3. **Full-Screen Matrix Hacker Terminal:**
   - Dedicated command-line terminal view (`VexorNull@BinaryCipher-Terminal`) featuring live hacker-style command processing (`encrypt`, `clear`, `help`, `exit`).
4. **Live Auto-Conversion & Entropy Security Meter:**
   - Real-time character/word counting alongside a dynamic entropy strength meter (*Low*, *Weak*, *Secure*, *Enterprise*).
5. **Customizable Theme Accent Switcher:**
   - Instantly toggle between 4 aesthetic cyber glows: **Cyan Glow**, **Emerald Green**, **Neon Purple**, and **Amber Orange**.
6. **Preset Quick Test Payloads:**
   - Quick-load sample data payloads to test conversion pipelines instantly.
7. **Audio Feedback & Visual Effects:**
   - Built-in Web Audio API synthesized sound effects and dynamic background Matrix canvas animation.

## 🛠️ Technologies Used

- **HTML5 / CSS3**: Modern glassmorphism design, CSS variables, and flexible layouts.
- **JavaScript (ES6+)**: Custom cryptographic conversion algorithms, Web Audio API, and DOM manipulation.
- **External CDN Libraries**:
  - FontAwesome 6.4.0 — UI Icons
  - QRCode.js — Instant QR Code generation
  - CryptoJS 4.1.1 — Secure cryptographic hashing (SHA-256 / MD5)

   git clone https://github.com/vexornull/BinaryCipher-PRO.git

   *(No complex server setup or build step required!)*
